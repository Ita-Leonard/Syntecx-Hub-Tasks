#  Sales Performance Dashboard | Power BI TASK 1

## Project Overview

The **Sales Performance Dashboard** is an interactive Power BI report designed to provide a comprehensive overview of business sales performance across different dimensions including sales, orders, product categories, locations, customers, and shipping costs.

This dashboard enables stakeholders to monitor key business metrics, identify high-performing regions and customers, analyze sales trends, and make data-driven decisions through dynamic visualizations and slicers.

## Objectives

- Monitor overall sales performance
- Track order volume and product quantity sold
- Analyze sales trends over time
- Identify top-performing customers and states
- Compare sales distribution across product categories
- Evaluate shipping costs across different cities
- Enable interactive filtering for deeper analysis

##  Dashboard Features

### Executive KPI Cards
Provides an instant overview of the organization's overall performance through high-level metrics including:

- Total Sales
- Total Orders
- Average Order Value
- Total Quantity Sold

### Sales Trend Analysis

A line chart visualizes sales performance over time, allowing users to identify:

- Daily sales patterns
- Monthly performance trends
- Peak sales periods
- Sales fluctuations

### Sales by Category

A donut chart breaks down total sales across product categories, making it easy to identify which categories contribute the most revenue.


### Geographic Sales Analysis

An interactive map displays total sales by state, helping users:

- Identify high-performing regions
- Detect low-performing markets
- Understand geographical sales distribution

### Customer Performance Analysis

A detailed matrix provides customer-level insights including:

- Customer Name
- Total Sales
- Country
- Quantity Purchased
- Brand Purchased

This helps identify top customers and purchasing behavior.

### Sales vs Shipping Cost

A combined column and line chart compares:

- Total Sales
- Shipping Cost

across different cities, enabling analysis of operational costs relative to revenue.


##  Interactive Features

The dashboard includes dynamic slicers that allow users to filter the report by:

- Brand
- Customer Name

These filters automatically update all visuals, enabling detailed and customized analysis.
